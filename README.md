# Population dynamics explorer

An interactive app to explore discrete population models in ecology,
built for high school students and science outreach.

**[Live app](https://yourusername.github.io/population-app)**

## Models

- **Exponential growth** — N_{t+1} = r · N_t
- **Logistic growth** — N_{t+1} = N_t + r · N_t · (1 - N_t/K)
- **Two-species interactions** — coming soon

## About

Developed for workshop on ecological modelling for highschool students.
as part of science outreach activities at [your institution].

Built with [React](https://react.dev) and [Recharts](https://recharts.org).
