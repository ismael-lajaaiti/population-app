# An Application to Introduce Ecological Models

An interactive app to explore discrete population models in ecology,
built for high school students and science outreach.

## About

Developed for workshop on ecological modelling for highschool students,
as part of science outreach activities at [INRAE, Rennes](https://www.inrae.fr/centres/bretagne-normandie).

Built with [React](https://react.dev) and [Recharts](https://recharts.org) using Claude.
